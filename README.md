# Library Management System

## 1. Project Overview

Library Managment system imitiates the real life library.

---

## 2. Features

The program allows different functionalities such as

1. Register a member
2. Reserve a book
3. Return a book
4. Add a book the library
5. Remove a book from the library
6. Display books catalog
7. Display all members
8. Save members data to a file
9. Load members data from the saved file
10. Save books data to a file
11. Load members data from the save file
12. Delete all members
13. Delete all books

---

## 3. Build & run instructions
### Build the project
```bash
make
```
### Run the program
```bash
./library
```
### Clean compiled files
```bash
make clean
```
